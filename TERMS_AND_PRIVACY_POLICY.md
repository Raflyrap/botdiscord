# FlyBot - Privacy Policy

Last Updated: October 2026

Your privacy is very important to us. This Privacy Policy outlines what information FlyBot ("the Bot") collects, how it is used, and how it is protected.

### 1. What Data We Collect
FlyBot only collects and processes minimal data strictly required to deliver its features:
- **Server IDs & Channel IDs**: Stored to remember configurations such as Welcome Channel, Temporary Voice Channel, Server Stats channels, and AI Chat channels.
- **Role IDs**: Stored to manage Auto-Role configurations set by server administrators.
- **User IDs & Experience Points (XP)**: Stored locally in database/config files for the leveling and ranking system.
- **Temporary Voice State**: Monitored in real-time solely to create and delete dynamic temporary voice rooms when members join or leave.

### 2. What Data We DO NOT Collect
- We **DO NOT** store personal sensitive data (passwords, payment information, personal identity).
- We **DO NOT** store message logs, chat history, or private direct messages (DMs).
- We **DO NOT** record, save, or store voice communications. Voice AI audio streams and music playback are processed strictly in temporary volatile memory (RAM) in real-time and are never written to disk or recorded.

### 3. How We Use Collected Data
Collected data is used strictly for:
- Executing requested Discord slash commands and interactive menu buttons.
- Maintaining server-specific preferences (e.g., custom welcome messages, leveling leaderboards).
- Displaying real-time server member counters and statistics.

### 4. Data Sharing & Third Parties
FlyBot does not sell, rent, or trade your data with third parties.
- If AI Chat or Voice AI features are used, text prompts and real-time voice buffers sent to the bot are processed via official OpenAI APIs solely to generate responses, under enterprise-grade ephemeral API privacy terms without retention.

### 5. Data Retention & Deletion
- Server configurations and leveling stats are retained only for as long as FlyBot remains in the server.
- Server owners can request complete deletion of their server's configuration and data at any time by kicking FlyBot or contacting the developer.

### 6. Security
We take appropriate technical and organizational measures to protect collected data against unauthorized access, loss, or alteration.

### 7. Contact Us
If you have any questions or wish to request data removal, please contact:
- Developer: Raflyrap
- Discord Support Server / Profile: FlyBot Developer Team
